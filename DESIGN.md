# NeuroKit Design Guide

This document defines the core visual direction for the NeuroKit company website.

## Brand Personality

NeuroKit should feel:

- trustworthy
- intelligent
- motivating
- youthful but not childish
- polished enough for investor review

The overall tone should balance academic focus with optimism and momentum.

## Color Palette

### Primary Colors

- `#0B3484` - primary blue
- `#FEEC4E` - primary yellow

These two colors should carry the main brand identity across the site.

Suggested usage:

- `#0B3484` for headlines, key surfaces, navigation accents, and important calls to action
- `#FEEC4E` for highlights, emphasis, badges, selected details, and energetic accent moments

### Supporting Colors

- `#DFDBD5` - light neutral
- `#BDBAB5` - muted neutral

Suggested usage:

- `#DFDBD5` for soft backgrounds, cards, sections, and subtle dividers
- `#BDBAB5` for borders, secondary UI elements, muted labels, and quiet supporting surfaces

## Typography

NeuroKit uses:

- `Poppins`
- `Ovo`

Suggested roles:

- `Poppins` for UI, navigation, buttons, labels, and body text
- `Ovo` for hero headlines, section titles, and brand-forward editorial moments

This pairing should create a modern product feel with a slightly thoughtful, human tone.

## Visual Direction

The site should avoid looking like a generic SaaS landing page.

Design principles:

- strong contrast between blue and yellow brand moments
- clean, spacious layouts
- soft neutral surfaces to keep the palette grounded
- confident typography with clear hierarchy
- mobile-first readability
- a modern company profile feel rather than a dashboard aesthetic

## UI Notes

- Buttons should feel bold and clear, not overly rounded or playful
- Cards should use subtle neutral backgrounds with enough spacing to feel premium
- Accent yellow should be used deliberately so it stays high impact
- Blue should anchor trust, credibility, and structure across the experience

## Implementation Notes

When building the website, prefer defining these as shared CSS variables or Tailwind theme tokens so the palette and typography stay consistent across pages.
